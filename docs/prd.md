# PRD：iPhone TrueDepth 人脸扫描重建

## 要解决的问题

手机上有 TrueDepth 传感器，但"用它扫一张脸、得到一个真三维模型"这件事，对普通用户和 AI agent 都不好用：官方能力要么单帧取景（没有模型），要么给的是参数化模板脸（不是真扫描几何），要么藏在闭源 App 里。

## 目标用户

- 想给自己或他人扫一张脸、拿到可导出的 3D 模型（3D 打印、数字人、测量、存档）的人。
- **以及 AI agent**：这是本项目的核心差异——整条链路设计成 agent 可驱动，agent 能启动扫描、等待用户扫完、拉回数据、融合出模型，全程无需人手动点 App。

## 需求

1. iPhone 端采集 App 能录出多角度关键帧（深度 + 位姿 + 内参 + 彩色），落盘到可被外部拉取的容器目录。
2. Mac 端能把一次扫描融合成三维网格并导出。
3. 控制面用 `devicectl`：agent 能通过 deep link 启停扫描、轮询状态、搬运数据，不依赖网络权限。
4. 契约稳定、可验证：iPhone 与 Mac 通过冻结的目录/JSON/schema 通信。
5. 可被其他 AI 接手：清晰的 skill、脚本入口与文档。

## 成功标准

- App 能在目标机型上编译、签名、安装、启动、录出扫描（真机验证）。
- Mac 上一条命令把扫描融成五官可见的网格。
- 合成数据单测证明位姿/内参约定正确（约定写错测试必失败）。
- public repo 无隐私泄漏。

## 非目标（v1 不做）

- 端侧实时融合（Phase 2）。
- 非刚性形变 / 表情捕捉（v1 要求中性表情 + 脸静止）。
- NeRF / 3D Gaussian Splatting。
- 头发/眼镜/瞳孔等 IR 硬缺口的补全。
